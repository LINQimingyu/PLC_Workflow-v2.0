# 上游与方案参考

## 实际采用的源码基线

- 仓库：[Arienax/gxworks-agent](https://github.com/Arienax/gxworks-agent)
- 固定提交：[c3a0f0b1acab12964ccb6004841c8de4b26ad1d2](https://github.com/Arienax/gxworks-agent/commit/c3a0f0b1acab12964ccb6004841c8de4b26ad1d2)
- 原作者版权、Apache-2.0 及第三方范围说明保留在 `app/LICENSE`、`LICENSE-SCOPE.md`、`NOTICE` 和 `THIRD_PARTY_NOTICES.md`。
- 扩展只在 Web bootstrap 注册 CIM 服务、增加工厂前端入口和独立 `src/cim` 业务域。工程服务、原生路径、CSV 解析、版本和验证工具复用上游。
- 前端回归新增 Playwright 开发依赖；仿真使用 [SimPy](https://simpy.readthedocs.io/en/latest/)，未引入 Docker。
